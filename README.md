**Пример:**

-   x = 5.25 → результат: 0.25

**Формула:** fraction(x) = x - static_cast\<int\>(x)

**Пример выполнения:** x = 5.25 - static_cast\<int\>(5.25) = 5 - 5.25 -
5 = 0.25.

**Пример выполнения:** a = 5, b = 1 - minVal = 1, maxVal = 5 - 3 \>= 1

Текст задачи

Поиск максимального. Дана сигнатура функции: int maxAbs(int arr\[\]);.
Необходимо реализовать функцию таким образом, чтобы она возвращала
наибольшее по модулю (то есть без учета знака) значение массива arr.
(Размер массива не передаётся - используется маркер конца 0.)

**Пример:** arr = \[1, -2, -7, 4, 2, 2, 5\] → результат: -7

Алгоритм решения

1.  Инициализировать best = arr\[0\] - первым элементом массива (а
    **не** 0, иначе для массива из отрицательных чисел результат будет
    неверным).
2.  Идти по массиву от i = 1 до маркера 0.
3.  Для каждого элемента считать его модуль через тернарный оператор:
    absI = arr\[i\] \< 0 ? -arr\[i\] : arr\[i\].
4.  Сравнивать модуль текущего элемента с модулем best. Если больше -
    обновить best = arr\[i\].
5.  Вернуть best - **сам элемент**, а не его модуль (по условию).

**Структура:**

int best = arr\[0\];

for (int i = 1; arr\[i\] != 0; ++i) {

const int absI = arr\[i\] \< 0 ? -arr\[i\] : arr\[i\];

const int absBest = best \< 0 ? -best : best;

if (absI \> absBest) best = arr\[i\];

}

return best;
