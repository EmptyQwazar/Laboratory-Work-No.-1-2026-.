Задача 1

Текст задачи

Дробная часть. Дана сигнатура функции: double fraction(double x);.
Необходимо реализовать функцию таким образом, чтобы она возвращала
только дробную часть числа x. Подсказка: вещественное число может быть
преобразовано к целому путем отбрасывания дробной части.

**Пример:**

-   x = 5.25 → результат: 0.25

Алгоритм решения

1.  Привести вещественное число x к целому типу int с помощью
    static_cast\<int\>(x) - при этом дробная часть отбрасывается.
2.  Вычесть полученное целое значение из исходного числа x.
3.  Результат вычитания --- это дробная часть числа x (с сохранением
    знака).

**Формула:** fraction(x) = x - static_cast\<int\>(x)

**Пример выполнения:** x = 5.25 - static_cast\<int\>(5.25) = 5 - 5.25 -
5 = 0.25.

Тестирование

Входные данные: x = 5.25. Ожидаемый результат: 0.25.

Текст задачи

Диапазон. Дана сигнатура функции: bool isInRange(int a, int b, int
num);. Функция принимает левую и правую границу (a и b) некоторого
числового диапазона. Необходимо реализовать функцию таким образом, чтобы
она возвращала true, если num входит в указанный диапазон (включая
границы). Обратите внимание, что отношение a и b заранее неизвестно
(неясно, кто из них больше, а кто меньше).

**Пример 1:** a = 5, b = 1, num = 3 - результат: true\
**Пример 2:** a = 2, b = 15, num = 33 - результат: false

Алгоритм решения

1.  Так как отношение a и b неизвестно, нужно сначала определить минимум
    и максимум из двух чисел.
2.  Минимум: minVal = a \< b ? a : b.
3.  Максимум: maxVal = a \> b ? a : b.
4.  Проверить, что num находится между minVal и maxVal включительно.

**Условие:** return num \>= minVal && num \<= maxVal;

**Пример выполнения:** a = 5, b = 1 - minVal = 1, maxVal = 5 - 3 \>= 1
&& 3 \<= 5 - true.

Тестирование

Входные данные: a = 5, b = 1, num = 3. Ожидаемый результат: true.

то вернуть надо false. Подсказка: оператор % позволяет получить остаток

**Пример 1:** x = 5 - результат: true\

    -   Если div3 = false, div5 = true - true
    -   Если div3 = true, div5 = true - false (делится на оба)

максимум, и мы поочерёдно сравниваем с ней все числа.

**Две инструкции **if** - без вложенности.**

Задача 3

Текст задачи

Поиск максимального. Дана сигнатура функции: int maxAbs(int arr\[\]);.
Необходимо реализовать функцию таким образом, чтобы она возвращала
наибольшее по модулю (то есть без учета знака) значение массива arr.
(Размер массива не передаётся - используется маркер конца 0.)

**Пример:** arr = \[1, -2, -7, 4, 2, 2, 5\] → результат: -7

Алгоритм решения

1.  Инициализировать best = arr\[0\] - первым элементом массива (а
    **не** 0, иначе для массива из отрицательных чисел результат будет
    неверным).
2.  Идти по массиву от i = 1 до маркера 0.
3.  Для каждого элемента считать его модуль через тернарный оператор:
    absI = arr\[i\] \< 0 ? -arr\[i\] : arr\[i\].
4.  Сравнивать модуль текущего элемента с модулем best. Если больше -
    обновить best = arr\[i\].
5.  Вернуть best - **сам элемент**, а не его модуль (по условию).

**Структура:**

int best = arr\[0\];

for (int i = 1; arr\[i\] != 0; ++i) {

const int absI = arr\[i\] \< 0 ? -arr\[i\] : arr\[i\];

const int absBest = best \< 0 ? -best : best;

if (absI \> absBest) best = arr\[i\];

}

return best;

Тестирование

Входные данные: массив \[1, -2, -7, 4, 2, 2, 5\]. Ожидаемый результат:
-7.

Входные данные: массив \[-3, -5, -1\]. Ожидаемый результат: -5.
